# servindoor

Sistema de gerenciamento, portaria, validação e sorteios da Festa do Servidor.

## 🚀 Tecnologias

- **Backend:** FastAPI (Python), SQLAlchemy, PostgreSQL
- **Frontend:** Vue 3, Vite, Pinia
- **Infra:** Docker & Docker Compose
